# 关于 WikitDB

WikitDB 是一个 **面向 Wikidot 社区生态的非营利性同人项目**，致力于把散落在各个分站的页面、作者、评分、论坛数据串联起来，为读者和作者提供统一的检索、追踪与分析体验。

本站由 Laimu_slime 主持开发，在 lestday233 奠定的经典架构基础上进行了全面的底层重构与视觉升级；LOGO 由 bairan317 倾力制作；核心数据接口由 **Wikit API** 提供强力支撑。

---

## 核心能力

### 页面归档
- 实时同步来自 Wikit API 的各分站页面元数据
- 支持按站点、标签、评分区间、发布时间多维筛选
- 保留已从原站点地图消失的历史页面（`--keep-removed`）

### 作者追踪
- 收录作者在不同分站的创作与评分走势
- 可按标签、站点、时间范围细化分析
- 绑定账号后可订阅作者动态

### 虚拟股市（作者概念股）
- 把创作产出、评分变化、互动数据转化为波动曲线
- 在充满博弈的虚拟市场中挖掘被低估的潜力新星

### 论坛同步
- 支持已接入分站的论坛帖子索引与搜索
- 保留 authorId / threadId / parentId 关系，可还原完整回帖树

### 实用工具集
- 盲盒抽取、删除公告生成、质量评审
- 奖励发放、交易市场、会员自助申请等社区常用工具
- 管理员专属：Wikit 备份管理工具

## 我们的理念

> **连接创作与未来的纽带**

- **非营利**：无广告、无付费墙，所有功能免费开放
- **社区驱动**：围绕 Wikidot 社区生态设计，优先服务作者与读者
- **隐私友好**：不索要不必要的个人信息；短信验证仅用于防机器人注册，不与第三方共享
- **开放透明**：代码开源在 GitHub，所有架构决策可被社区审视与贡献

## 常见问题

**Q: 使用 WikitDB 需要账号吗？**
大部分检索与浏览功能无需登录。作者追踪、虚拟股市、高级搜索等与账户绑定的数据功能需要注册账号。注册免费，花不了一分钟。

**Q: 数据多久更新一次？**
备份任务每天 12:00（Asia/Shanghai）自动执行；Wikit API 侧的实时接口会尽可能快地反映 Wikidot 平台上的最新内容。

**Q: 我的文章被收录进来了，但不希望这样？**
请通过社区渠道联系管理员，我们会在核验身份后对特定条目进行遮蔽。WikitDB 本质是为读者服务的索引工具，不替代原站点的权威发布。

**Q: 为什么要短信验证？**
仅用于防机器人刷号，避免虚拟股市和论坛同步工具被恶意滥用。短信验证记录不会与任何第三方共享。

## 技术栈一览

- **前端框架**：Next.js Pages Router + React 18 + Tailwind CSS
- **后端存储**：PostgreSQL via Prisma ORM
- **抓取与同步**：kakushi-w/wikit CLI，Wikit GraphQL API
- **论坛渲染**：FTML (Wikidot 文本标记语言) WASM 内核
- **安全与基础设施**：JWT (HS256)、bcrypt、CSRF Origin 校验、IP 双层限速
